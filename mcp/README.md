# gjalla MCP server manifest

This folder hosts the `server.json` manifest for the **gjalla MCP server**, published to the [official MCP Registry](https://registry.modelcontextprotocol.io/) and crawled by downstream MCP directories.

## Install

This surfaces gjalla's remote MCP server. Point your MCP client at:

```
https://gjalla.io/mcp/stream
```

Auth: Bearer token via the `Authorization` header. Generate an API key at https://gjalla.io/account/api-keys.

## Source

The MCP server is hosted in the gjalla web service (proprietary). This repo holds the public manifest, skills, and integration docs.

- Website: https://gjalla.io
- Docs: https://gjalla.io/docs
